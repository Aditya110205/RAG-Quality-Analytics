DuckDB as analytical warehouse:
- Embedded OLAP database, no server needed
- Reads Parquet directly from S3 (httpfs extension)
- SQL interface: familiar, powerful, fast columnar execution
- Supports: window functions, JSON, array operations
- CREATE VIEW for marts, materialized for performance
- Connects to Python, R, Node, CLI, ODBC
- Free, open-source, single binary

Replaces Postgres/BigQuery for local dev and small-team analytics.
