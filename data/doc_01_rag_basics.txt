RAG (Retrieval-Augmented Generation) is an architecture that combines information retrieval with text generation. Instead of relying solely on an LLM's parametric knowledge, RAG retrieves relevant documents from a knowledge base and provides them as context to the LLM. This reduces hallucinations and allows the system to answer questions about private or recent data not seen during training.

Key components:
1. Document ingestion: Load and preprocess documents
2. Chunking: Split documents into smaller passages
3. Embedding: Convert chunks to vector representations
4. Vector store: Index embeddings for fast similarity search
5. Retrieval: Find top-K relevant chunks for a query
6. Generation: Feed chunks + query to LLM for final answer
